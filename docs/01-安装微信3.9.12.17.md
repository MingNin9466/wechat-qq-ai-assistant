# 安装微信 3.9.12.17（hook 方案必需）

> 为什么必须装这个版本：WeChatFerry 的 SDK（v39.4.5）是按微信 3.9 系列的内存结构写死的，4.x 改成了 Electron 架构，注入完全不通。
>
> 好消息：**3.9 和 4.x 可以共存**。它们装在不同目录、用不同数据目录（3.9 用 `Documents\WeChat Files`，4.x 用 `Documents\xwechat_files`），互不影响。

## 1. 安装包

已下载并校验完成：

```
C:\Users\你的名字\微信群聊deepseek\tools\wechat\WeChatSetup-3.9.12.17.exe
```

| 项 | 值 |
|---|---|
| 大小 | 284,144,184 字节（271.0 MB） |
| SHA256 | `4985f96235154fc4176e3972f14709f5f10fc0606e5589075a6da9b6dc7fccd3` |
| 数字签名 | ✅ Valid — `CN=Tencent Technology (Shenzhen) Company Limited` |
| 文件版本 | 3.9.12.1000 |

来源：`tom-snow/wechat-windows-versions` 的 v3.9.12.17 release。
GitHub 原始地址（直连很慢，需用 gh-proxy 前缀下载）：
`https://github.com/tom-snow/wechat-windows-versions/releases/download/v3.9.12.17/WeChatSetup-3.9.12.17.exe`

> 注意：`gh-proxy.com` 只能代理**文件**，直接打开 GitHub 网页链接会提示 "Web page content is not allowed"。要么直连 github.com 看页面，要么把 `https://gh-proxy.com/` 拼在真实下载地址前面。

## 2. 安装

双击安装包，**安装路径改成纯英文**，例如：

```
D:\WeChatBot
```

> ⚠️ 不要装在中文路径或带空格的路径下，后面注入和启动脚本都会出问题。
> ⚠️ 不要覆盖你现在的 4.1（安装时如果提示"已安装"，选另一个目录，不要卸载新版）。

安装完成后**先不要登录你的主号**。

## 3. 关闭自动更新（关键）

微信 3.9 会在后台自动升级到 4.x，一升级 hook 就废了。

### 本机实际路径

你装在了 `D:\WeChatBot`，版本子目录多一层：

```
D:\WeChatBot\WeChat\[3.9.12.17]\
    WeChat.exe                  ← 主程序（不动）
    WeChatUpdate.exe            ← 更新程序（要处理）
    WeChatUpdate.bin            ← 更新程序的资源（可以不管）
```

> 注意：不同安装方式目录结构不一样。有的直接在 `...\WeChat\[3.9.x.x]\`，有的是
> `...\WeChatBot\WeChat\[3.9.x.x]\`。找的方法是：右键桌面微信快捷方式 →
> **打开文件所在位置**，看到 `[3.9.12.17]` 这种带方括号的文件夹，进去就是。

### 已完成的处理（本机 2026-10-23）

| 操作 | 结果 |
|---|---|
| `WeChatUpdate.exe` 改名为 `WeChatUpdate.exe.disabled` | ✅ 2.43 MB，原文件保留 |
| 新建**同名文件夹** `WeChatUpdate.exe` 占位 | ✅ 空文件夹，挡住更新程序重新生成 |
| 验证「同名路径无法创建文件」 | ✅ 被系统拒绝 |
| `WeChat.exe` 完好 | ✅ |
| `WeChatUpdate.bin` | 保留未动（无害） |

最终目录长这样：

```
[3.9.12.17]\
  WeChat.exe
  WeChatUpdate.exe          ← 文件夹（占位）
  WeChatUpdate.exe.disabled ← 原更新程序
  WeChatUpdate.bin
```

### 自己动手的话（换台电脑时）

1. 打开 `...\[3.9.12.17]\`
2. 把 `WeChatUpdate.exe` 改名为 `WeChatUpdate.exe.disabled`
3. 在同一目录「新建 → 文件夹」，命名 `WeChatUpdate.exe`
   - 资源管理器会提示「如果改变文件扩展名…」，点**是**
4. 完事

### 回退（万一把事情搞坏了）

PowerShell 里执行（路径用 `-LiteralPath`，否则方括号会被当通配符）：

```powershell
$dir = 'D:\WeChatBot\WeChat\[3.9.12.17]'
Remove-Item -LiteralPath "$dir\WeChatUpdate.exe" -Force -Recurse
Rename-Item  -LiteralPath "$dir\WeChatUpdate.exe.disabled" -NewName 'WeChatUpdate.exe'
```

### 如果微信还是提示更新

说明它是先下载完整安装包再执行，不依赖本地这个 `WeChatUpdate.exe`。追加一层兜底（需要管理员）：

用记事本以管理员身份打开 `C:\Windows\System32\drivers\etc\hosts`，加两行：

```
127.0.0.1 dldir1.qq.com
127.0.0.1 dldir1v6.qq.com
```

（这俩是微信/QQ 客户端的下载 CDN，不影响聊天、图片、文件收发。想撤销删掉这两行即可。）

## 4. 用专用小号登录

1. 用**小号**扫码登录这个 3.9.12.17
2. 把机器人拉进你的测试群
3. **主号继续用 4.1**，两边不冲突
   - 注意：同一个微信号**不能**同时在 3.9 和 4.x 上登录，所以小号只登 3.9

## 5. 验证

回到项目目录：

```powershell
npm run doctor
```

应该看到：

```
✔ 微信客户端     检测到：3.9.12.17、4.1.15.56
```

如果还是显示"检测到：4.1.15.56"，说明装到了别的目录，把 `WeChat.exe` 所在目录告诉我，我加进扫描列表。

## 6. 启动机器人

```powershell
npm start
```

首次启动会注入 DLL（几秒），日志里出现 `微信登录成功` 就成了。
在群里 @ 机器人 说句话试试。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `启动 WeChatFerry 失败` | 微信没登录 / 版本不对 | 确认 3.9.12.17 已登录且窗口在 |
| 注入后微信闪退 | 杀毒软件拦截 | 把安装目录加进白名单（火绒/360 常见） |
| 收不到群消息 | 群没加进白名单 | `.env` 的 `ALLOWED_ROOMS` 留空，或填群 id |
| `@` 了没反应 | 机器人昵称和 `BOT_NAME` 不一致 | 把 `.env` 的 `BOT_NAME` 改成微信里显示的名字 |
| 反复掉线 | 小号被风控 | 停一天别用，换第二个小号 |

## 8. 卸载 / 回退

3.9 是独立安装，直接卸载不影响 4.1。数据在 `Documents\WeChat Files\`，一并删除即可。
