# B 站视频脚本：我给自己的群写了个 AI 管家

> 时长目标 **2 分 30 秒 ~ 3 分钟**
> 风格：屏幕录制 + 画外音，节奏快一点，别念稿
> 封面文案建议：**「我在微信群里塞了个 AI，它还会发语音」**

---

## 分镜

### 00:00 - 00:15 开场：先给结果

**画面**：微信群里，你发 `@小助手 在吗`，它秒回一条**文字**，紧接着一条**语音**，再跟一张**表情包**。

**画外音**：

> 这是我自己群里的一个 AI，它叫「小助手」。
> 你 @ 它，它回你；你发图，它看得懂；你发 B 站链接，它能看完给你讲；
> 它还会用我复刻的音色发语音。

### 00:15 - 00:40 它到底能干什么（快剪）

**画面**：快速切四个片段
1. 发一张表情包 → 它描述画面内容
2. 发一个 B 站链接 → 它回「我看完了，这视频讲的是……」
3. 问「今天有什么新闻」→ 它联网回答
4. QQ 群里同样操作

**画外音**：

> 看图、看视频、联网、语音、表情包——而且**微信和 QQ 是同一个大脑**。
> 同一套人设、同一份记忆，但每个群、每个人单独记忆，不会串。

### 00:40 - 01:10 记忆和人格（重点）

**画面**：打开管理后台 → 人格页 → 展示规则；再切记忆页 → 展示记忆列表、核心记忆、共享记忆确认队列。

**画外音**：

> 这台后台才是重点。
> 人格可以按群单独设，也能一键复制到所有群；
> 记忆是分层的——消息压成摘要，摘要再提炼成记忆，
> 我勾一下「设为核心」，它就永远记得。
> 它还会自己写日记，每天 23:30 自动写。

### 01:10 - 01:40 它自己会学习

**画面**：后台调试页 → 点「刷个视频学习」→ 展示返回的视频标题和感想；再点「同步 B 站信笺」→ 展示待确认队列。

**画外音**：

> 它每 3 小时自己去 B 站刷一个视频，看画面、看简介，写一句「我从中了解到人类什么」。
> 学到的内容不会直接进记忆——先进「待确认」，
> 我觉得有价值才点通过，它才会真正记住。

### 01:40 - 02:10 语音（这段最抓人）

**画面**：QQ 群里点一下那条语音条播放；再切到后台「设定 → 语音」，展示引擎/音色/资源标识三项。

**画外音**：

> 语音这块我用的是豆包的 TTS，音色是**复刻**的——
> 我上传了 15 秒参考音频，它就学会了那个声音。
> QQ 发的是**原生语音条**，点开就能听；
> 微信只能发 mp3 文件，因为微信的语音条要走它内部接口，UI 自动化做不到。

### 02:10 - 02:30 成本与规模

**画面**：后台概览 → 按会话用量表（各群调用次数、花费）、对话热度表。

**画外音**：

> 每个群、每个人花了多少钱、发了多少条，后台一目了然。
> 我这两个群跑了 600 多次对话，花了一块二。

### 02:30 - 02:50 结尾：开源 + 提醒

**画面**：GitHub 仓库首页（README + 星星位置），最后停在「MIT License」。

**画外音**：

> 代码我开源了，MIT 协议，链接在简介。
> 但先说清楚：微信**没有**个人群的官方机器人接口，
> 我用的是 UI 自动化，**有封号风险**，一定要用小号。
> 别拿它做营销、骚扰，那会害了所有人。

**结尾字幕**：

```
GitHub: github.com/你的用户名/wechat-qq-ai-assistant
MIT License · 用爱发电
```

## 录屏前的准备清单

- [ ] 微信小号已登录，目标群都已「在独立窗口中打开」
- [ ] QQ（NapCat）已启动并登录
- [ ] 管理后台打开好 `http://127.0.0.1:8898`
- [ ] 关掉桌面上的隐私窗口（聊天记录里别出现真实姓名、手机号）
- [ ] 群聊截图前先检查：**别把别人的隐私发出去**
- [ ] 录屏软件：OBS / 剪映录屏都行，1080p 60fps
- [ ] 麦克风先试录 10 秒，确认没爆音

## 剪辑建议

1. **开头 3 秒必须给结果**（语音条 + 表情包），不要放 logo
2. 快剪段落每段不超过 3 秒，配节奏点
3. 语音那一段**别配音**，直接放原声，让人听清
4. 全程加字幕（B 站没字幕完播率会掉）
5. 结尾留 5 秒静帧放仓库地址
